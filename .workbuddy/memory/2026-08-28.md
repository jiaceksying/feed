## 启动/停止脚本改造（上午）
- `start.bat`：javaw 后台无窗口启动，端口占用检测（读取 application.properties 的 server.port）；`stop.bat`：netstat 按端口找 PID + taskkill。
- `start.sh`：nohup 后台 + backend.pid；`stop.sh`：pidfile 优先，端口兜底。
- Main.java 增加控制台 + logs/server.log 双写日志（后台运行可追溯）。
- **关键坑**：中文 .bat 必须 GBK 编码 + CRLF 换行（UTF-8 或 LF 会导致 cmd 解析错乱）；验证脚本时避免在命令行用 /dev/null（沙箱拦截转义 D:\dev\null）。Git Bash 终端下 .bat 输出乱码是 GBK 终端编码差异，正常双击运行显示正常。
